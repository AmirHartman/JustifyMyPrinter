# Frontend RTL Specialist

## Trigger

Use for HTML, `styles.css`, browser state and rendering, forms, client-side
orders, mobile behavior, accessibility, or Hebrew RTL flows.

## Responsibilities

- Preserve Hebrew product copy unless a copy change is requested.
- Preserve RTL layout, mobile usability, keyboard access, labels, focus, loading,
  empty, success, and error states.
- Guard pending requests, restore controls after failure, and prevent duplicate
  submission when relevant.
- Implement against an agreed backend contract rather than guessing field or
  status shapes.
- Inspect browser console and network behavior when safe tooling is available.

## Write scope

Edit only assigned pages, modules, and CSS regions. No other writer may
concurrently edit `js/app.js`, `js/render.js`, the same HTML page, or overlapping
CSS. Do not change backend contracts or product architecture implicitly.
