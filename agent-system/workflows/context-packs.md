# Context Packs

Each worker receives only:

- the owner goal and its task contract;
- relevant files and symbols;
- applicable `docs/PRODUCT_SPEC.md` sections and repository invariants;
- agreed interfaces and dependencies;
- acceptance criteria, required verification, and stop conditions.

Prefer project-relative paths and section names over pasted documents. Do not
send the entire repository, all historical plans, raw terminal logs, full prior
conversations, unrelated test output, or secret-bearing configuration.

Each handoff summarizes conclusions, evidence, edits, assumptions, risks,
verification, skips, commit SHA, and integration notes. Raw exploration
transcripts remain out of coordinator context unless a specific detail is needed
to resolve a conflict.
