הגדרת הגשר המקומי

ההזמנות והאישור נשארים באתר. כאן מגדירים רק את החיבור המקומי והקבצים.

בעריכת הגדרה קיימת אפשר להשאיר את הסוד וקוד הגישה ריקים כדי לשמור אותם כפי שהם. ערכים אלה לעולם אינם מוצגים שוב.

חיבור למדפסת

הערכים נמסרים פעם אחת לתהליך המקומי ונשמרים בהצפנת Windows בלבד. אין להשתמש בקובץ ‎.env‎.
